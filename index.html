iitp 최신 기술이 적용된 RFP 작성

기존 수요조사서-RFP 연계 확인, ICT 기술분류 선택, 최신 뉴스·논문 검색, 수요조사서 및 RFP 자동 생성을 위한 실제 데이터 연동형 랜딩페이지입니다.

1. 기존 수요조사서-RFP 연계표

실제 IDEA/RFP 분석 결과를 기반으로 연계 후보를 자동 표시합니다.
입력 주제기술분류관련 수요조사서관련 RFP연계강도연계 근거
입력값을 반영하면 연계 결과가 표시됩니다.

2. 기술분야 선택 영역

Tech Tree 기준 용어만 사용합니다. 자동 추출이 어려운 항목은 주석과 함께 예시 옵션으로 제공됩니다.

3. 최신 뉴스·논문 검색창

선택한 기술분야와 주제를 기준으로 최신 정보보호 뉴스와 논문을 검색하는 구조입니다.
제목출처날짜핵심 이슈신규과제 아이디어 연계 가능성
검색 실행 시 결과가 표시됩니다. 실제 검색 API 연동용 구조만 구현되어 있습니다.

4. 수요조사서 및 RFP 작성 실행 영역

입력값과 검색 결과를 종합해 Agent 실행용 프롬프트를 만들고, 추후 백엔드 또는 LLM API와 연결할 수 있도록 구성했습니다.
생성 결과가 여기에 표시됩니다.
