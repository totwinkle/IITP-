에이전트 안내

상단 소개는 제거하고, 아래에서 최신 연구주제 검색부터 바로 진행합니다.

검색부터 시작 중복성 검토 포함

1. 최신 연구주제 검색 → NTIS 중복성 검토 → 저중복 3개 추천

최근 기사, 논문, 특허, 학회지 발표내용을 먼저 반영하고, NTIS 기존 연구와의 중복 가능성을 검토한 뒤 중복성이 낮은 신규 연구주제 3개를 우선 추천합니다.
뉴스: 최근 3개월 논문: 최근 1년 특허: 최근 1년 학회: 최근 1년
검색 기준은 기본값으로 고정 가능하며, 필요 시 API/백엔드로 확장

NTIS 중복성 검토 및 추천 주제 정리

검색 조건으로 먼저 최신 후보를 모은 뒤, NTIS 기존 연구와 겹침을 검토하고 저중복 신규 연구주제 3개를 우선 추천합니다.

NTIS 연동 대기: API ID/PW 입력 후 상태 확인
NTIS API 엔드포인트, 파라미터명, 인증 방식은 실제 NTIS 오픈 API 문서에 맞춰 수정 가능하도록 JS 함수에 주석을 두었습니다. ID/PW는 localStorage, sessionStorage, cookie에 저장하지 않습니다.

2. 사용자 입력값

1단계에서 추천된 신규 연구주제 3개 중 하나를 선택한 뒤, 수요조사서와 RFP 생성을 위한 입력을 보완합니다.

3. 문서 생성 및 다운로드

2단계 입력값을 바탕으로 수요조사서와 RFP 초안을 생성한 뒤 다운로드합니다.

주석: 순수 HTML/JavaScript만으로는 `.doc` 형식 다운로드를 구현할 수 있습니다. `.docx`가 필요하면 JS 라이브러리 또는 백엔드 생성이 추가로 필요합니다.

5. 미리보기 영역

공공기관 문서 형식에 맞춰 제목, 목차, 본문 구조가 보이도록 구성했습니다.
