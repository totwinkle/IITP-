# RFP 생성기

사이버보안 분야의 최신 연구주제를 찾고, NTIS 중복성 검토를 거쳐, 수요조사서와 RFP 초안을 생성하는 단일 HTML 기반 도구입니다.

## 포함 파일
- `index.html`: 검색, 중복성 검토, 입력, 미리보기, 다운로드를 한 화면에 제공
- `cybersecurity_rfp_agent.md`: 에이전트 실행 지침서

## 사용 순서
1. 최신 연구주제 검색과 NTIS 중복성 검토를 진행합니다.
2. 중복성이 낮은 후보를 선택한 뒤 사용자 입력을 보완합니다.
3. 수요조사서와 RFP를 생성하고 다운로드합니다.

## 참고
- 브라우저에서 바로 열 수 있습니다.
- NTIS 실제 연동은 API 사양에 맞춰 추가 조정이 필요합니다.
